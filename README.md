# LittleCherish – Personalized Gifting Website

> **A modern, responsive, and user-friendly personalized gifting website designed to make every special moment more memorable.**

## About the Project

**LittleCherish** is a modern, responsive multi-page gifting website built using **HTML5, CSS3, and Tailwind CSS**.

It allows users to explore personalized gifts for birthdays, anniversaries, celebrations, and other special occasions. The website includes gifting collections, custom hampers, greeting cards, home décor, and supporting pages such as login, contact, FAQ, and order tracking.

## Key Features

- Personalized gifting collections
- Birthday & Anniversary gifts
- Love & Long-Distance gifts
- Festive gifts
- Custom hampers
- Home décor & New Parents collections
- Greeting cards
- Product & collection pages
- Login & account pages
- Order tracking
- FAQ & policy pages
- Responsive design for mobile, tablet & desktop

## Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layouts
- **Tailwind CSS** – Utility-first styling and responsive design
